# Anti-Patterns Verdict

* **LLM Assessment**: High tactile personality. Avoids generic SaaS templates with unique 3D floating cards and official One Piece TCG color bands. However, uses runtime `@import` Google Fonts inside inline `<style>` tags which causes render blocking and font-swapping layout shifts.
* **Deterministic Scan**: Verified DOM structure, header navigation links, and responsiveness across breakpoints.

---

# Overall Impression

The homepage makes a strong visual impression with its animated 3D card stack, live catalog counter, and interactive Rarity guide. It feels like an authentic TCG collector hub rather than a generic database. The main opportunities lie in integrating the **Dashboard** into the header/hero and modernizing the hero typography.

---

# What's Working

1. **Tactile 3D Hero Card Stack**: Floating cards that flip from authentic One Piece card backs (Leader vs Character) to reveal actual card artwork creates immediate delight.
2. **Interactive Rarity Guide**: Clicking any rarity tier opens a polished modal explaining pull rates, foiling treatments, and card roles.
3. **Built-in Game Theming**: The palette switcher in the header lets users customize themes with live preview thumbnails.

---

# Priority Issues

* **[P1] Missing Dashboard Navigation in Header**
  * *Why it matters*: Users arriving at the homepage cannot discover or access their Collection Dashboard from the top navigation bar.
  * *Fix*: Add "Dashboard" to the main nav links (`Dashboard`, `Cards`, `Binder`, `Don!!`, `About`) and link the hero "Track collection" CTA.
  * *Suggested command*: `clarify`

* **[P2] Dead User Avatar Button**
  * *Why it matters*: When logged in, clicking the user profile avatar circle in the header does nothing (`// onClick={() => router.push("/profile")}` is commented out).
  * *Fix*: Wire the avatar button to route to `/dashboard` or open a user quick menu.
  * *Suggested command*: `harden`

* **[P3] Runtime Font `@import` & Impact Fallback**
  * *Why it matters*: `@import url(...)` inside JSX `<style>` causes external network blocking and Cumulative Layout Shift (CLS). The `Impact` font fallback also renders with inconsistent letter-spacing across Mac, Windows, and mobile devices.
  * *Fix*: Move font loading to `next/font` or standardize typography tokens with the rest of the application.
  * *Suggested command*: `polish`
